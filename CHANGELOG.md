# Changelog

## Initial public release

- 17-page ops dashboard with a calm-terminal aesthetic.
- Live data integrations: Home Assistant, Proxmox, Portainer.
- Camera snapshot proxy with per-camera fallback.
- Room control page with light toggle + brightness slider.
- GitHub auto-sync for a projects list.
- Auth.js v5 + Prisma/SQLite, invite-only signup, login rate-limit, argon2id hashes.
- Security headers, Cloudflare-friendly defaults, per-host TLS scoping for self-signed origins.
- Unit tests via Vitest; e2e smoke tests via Playwright.
- Docker multi-stage build; GitHub Actions CI.
